JavaScript Login and Logout Logic
admin.html — JavaScript — Login and Logout
var ADMIN_PASSWORD = 'drukshift2026';
var API_BASE = 'https://drukshift-vakend.onrender.com';

function doLogin() {
  var pw = document.getElementById('loginPassword').value;
  if (pw === ADMIN_PASSWORD) {
    // Correct password — hide login, show dashboard
    document.getElementById('loginWrap').style.display     = 'none';
    document.getElementById('dashboardWrap').style.display = 'block';
    clearInterval(loginTimer);
    loadDashboard();
  } else {
    // Wrong password — show error, clear input
    document.getElementById('loginError').style.display = 'block';
    document.getElementById('loginPassword').value = '';
    document.getElementById('loginPassword').focus();
  }
}

function doLogout() {
  document.getElementById('dashboardWrap').style.display = 'none';
  document.getElementById('loginWrap').style.display     = 'flex';
  document.getElementById('loginPassword').value = '';
  document.getElementById('loginError').style.display   = 'none';
  loginTimer = setInterval(function(){ goToLoginSlide((loginSlide+1)%5); }, 4500);
}

ADMIN_PASSWORD constant — Password variable — The password is stored as a JavaScript variable. When the user submits, their input is compared to this value using strict equality ===.

pw === ADMIN_PASSWORD — Strict equality — Triple equals checks both value and type. 'drukshift2026' === 'drukshift2026' is true. 'Drukshift2026' === 'drukshift2026' is false (case sensitive).

clearInterval(loginTimer) — Stop slideshow — Once logged in the background slideshow is stopped to save browser resources since it is no longer visible.

loadDashboard() after login — Auto-load — Immediately fetches data from MongoDB and renders the dashboard as soon as the correct password is entered.

doLogout resets everything — Clean state — Hides the dashboard, shows the login page, clears the password field, hides any error message, and restarts the slideshow timer.

Note: This is client-side password checking — the password is visible in the JavaScript source code. For a production system a proper backend authentication system would be needed. For this internship project it is sufficient.
JavaScript Load Dashboard Data
admin.html — JavaScript — Fetch Data from MongoDB
async function loadDashboard() {
  document.getElementById('loadingState').style.display = 'block';
  document.getElementById('dashContent').style.display  = 'none';

  try {
    // Fetch users from MongoDB
    var usersRes  = await fetch(API_BASE + '/api/admin/users');
    var usersData = await usersRes.json();

    // Fetch quiz results from MongoDB
    var resultsRes  = await fetch(API_BASE + '/api/admin/results');
    var resultsData = await resultsRes.json();

    renderDashboard(usersData.users || [], resultsData.results || []);

    // Show last updated time
    var now = new Date();
    document.getElementById('lastUpdated').textContent =
      'Updated ' + now.toLocaleTimeString();

  } catch (err) {
    // Show error if backend is not reachable
    document.getElementById('loadingState').innerHTML =
      '<div class="empty-state">⚠️ Could not connect to backend.</div>';
  }
}

show loading, hide content — Loading pattern — Shows the spinner and hides the content first. After data loads it reverses this. This prevents showing empty or partially loaded charts.

Two separate fetch calls — Two API endpoints — Fetches users and results separately from two different backend API routes. Both are awaited before rendering.

usersData.users || [] — Fallback — If the backend returns an unexpected format and .users is undefined, the || [] provides an empty array as fallback to prevent errors.

try/catch block — Error handling — If the fetch fails (backend is down, no internet) the catch block runs and shows an error message instead of crashing the page.

toLocaleTimeString() — Formatted time — Converts the current date to a readable local time string like 10:30:45 AM and displays it as the last updated timestamp.

JavaScript Score Distribution Chart
admin.html — JavaScript — Score Distribution
function renderDistribution(scores) {
  var ranges = [
    { label:'90-100%', min:90, max:100, color:'#2a9d8f' },
    { label:'80-89%',  min:80, max:89,  color:'#52c78f' },
    { label:'70-79%',  min:70, max:79,  color:'#e9c46a' },
    { label:'60-69%',  min:60, max:69,  color:'#f4a261' },
    { label:'Below 60',min:0,  max:59,  color:'#e63946' }
  ];

  // Count how many scores fall in each range
  var counts = ranges.map(function(r) {
    return scores.filter(function(s) {
      return s >= r.min && s <= r.max;
    }).length;
  });

  var maxCount = Math.max.apply(null, counts);

  // Build HTML bars proportional to max count
  var html = '';
  for (var i = 0; i < ranges.length; i++) {
    var pct = maxCount > 0 ? Math.round((counts[i] / maxCount) * 100) : 0;
    html += '<div class="dist-row">' +
            '<div class="dist-label">' + ranges[i].label + '</div>' +
            '<div class="dist-track">' +
            '<div class="dist-fill" style="width:' + pct + '%;background:' +
            ranges[i].color + '"><span>' + counts[i] + '</span></div>' +
            '</div></div>';
  }
  document.getElementById('distBars').innerHTML = html;
}

ranges array of objects — Configuration — Defines each score band with its label, min, max, and bar colour. Easy to add or change bands by editing this array.

.filter() to count scores — Array filtering — For each range, filter keeps only the scores within that range. .length gives the count.

Math.max.apply(null, counts) — Find maximum — Finds the largest count across all ranges. Used to calculate proportional bar widths — the range with most respondents gets 100% bar width.

pct = counts[i] / maxCount * 100 — Proportional width — Calculates each bar as a percentage of the maximum count. This makes the chart scale correctly regardless of total respondent numbers.

Building HTML string — Dynamic rendering — Concatenates HTML strings in a loop and inserts them all at once with innerHTML. Each bar is a dist-row div with a label, track and fill.

JavaScript Domain Averages Chart
admin.html — JavaScript — Domain Averages
var DOMAIN_NAMES = ['Knowledge','Technical Skill','Trust',
  'Security Awareness','Personal Readiness','Infrastructure',
  'Digital Comfort','Regulatory Awareness','Adoption Willingness',
  'GNH Alignment'];

var DOMAIN_COLORS = ['#2a6aad','#2a9d8f','#e9c46a','#e63946',
  '#9b5de5','#f4a261','#2a9d8f','#d4537e','#2a9d8f','#e9c46a'];

function renderDomainAverages(results) {
  var totals = new Array(10).fill(0);
  var counts = new Array(10).fill(0);

  results.forEach(function(r) {
    if (r.answers && r.answers.length) {
      for (var i = 0; i < Math.min(r.answers.length, 10); i++) {
        totals[i] += r.answers[i];
        counts[i]++;
      }
    }
  });

  var html = '';
  for (var i = 0; i < 10; i++) {
    var avg = counts[i] ? (totals[i] / counts[i]).toFixed(1) : 0;
    var pct = Math.round((avg / 10) * 100);
    html += '<div class="domain-row">' +
            '<div class="domain-label">' +
            '<span>' + DOMAIN_NAMES[i] + '</span>' +
            '<span>' + avg + '/10</span>' +
            '</div>' +
            '<div class="domain-track">' +
            '<div class="domain-fill" style="width:' + pct + '%;background:' +
            DOMAIN_COLORS[i] + '"></div>' +
            '</div></div>';
  }
  document.getElementById('domainBars').innerHTML = html;
}

DOMAIN_NAMES and DOMAIN_COLORS arrays — Parallel arrays — Two arrays where index 0 of both correspond to Question 1. DOMAIN_NAMES[0] is Knowledge, DOMAIN_COLORS[0] is blue. Used together in the loop.

new Array(10).fill(0) — Initialise array — Creates an array of 10 zeros. Used to accumulate totals and counts for each domain across all results.

r.answers array — Quiz answers — Each quiz result in MongoDB stores the user's 10 answers as an array. r.answers[0] is their answer to Q1, r.answers[1] to Q2 etc.

totals[i] / counts[i] — Average calculation — After summing all answers for each domain, dividing by the count gives the average. toFixed(1) rounds to 1 decimal place.

pct = avg / 10 * 100 — Percentage — Converts the average score out of 10 to a percentage for the progress bar width.

function renderReadinessBreakdown(scores) {
  var high  = scores.filter(function(s){ return s >= 80; }).length;
  var mid   = scores.filter(function(s){ return s >= 60 && s < 80; }).length;
  var low   = scores.filter(function(s){ return s < 60; }).length;
  var total = scores.length || 1;

  var html = '<div style="display:flex;flex-direction:column;gap:14px;">';
  html += makeBand('🟢 Highly Ready (80%+)',         high, total, '#e1f5ee', '#085041');
  html += makeBand('🟡 Somewhat Ready (60-79%)',     mid,  total, '#faeeda', '#633806');
  html += makeBand('🔴 Needs Support (Below 60%)',   low,  total, '#fcebeb', '#a32d2d');
  html += '</div>';
  document.getElementById('readinessBreakdown').innerHTML = html;
}

function makeBand(label, count, total, bg, color) {
  var pct = Math.round((count / total) * 100);
  return '<div style="background:' + bg + ';border-radius:10px;padding:14px;">' +
    '<div style="display:flex;justify-content:space-between;">' +
    '<span style="color:' + color + '">' + label + '</span>' +
    '<span style="color:' + color + '">' + count + ' (' + pct + '%)</span>' +
    '</div></div>';
}

Three filter calls — Categorisation — The scores array is filtered three times to count how many fall in each readiness band. High is 80 and above, mid is 60-79, low is below 60.

total = scores.length || 1 — Division safety — If there are no scores, scores.length is 0. Dividing by 0 gives Infinity. Using || 1 means if length is 0 use 1 instead to prevent this.

makeBand helper function — Reusable function — Instead of writing the same HTML structure three times, a helper function is created. Called three times with different parameters to create each band.

function renderRecentActivity(results) {
  // Sort by date — newest first
  var sorted = results.slice().sort(function(a, b) {
    return new Date(b.takenAt) - new Date(a.takenAt);
  }).slice(0, 7); // Only show last 7

  var html = '<div style="display:flex;flex-direction:column;gap:8px;">';
  sorted.forEach(function(r) {
    var d  = new Date(r.takenAt);
    var ds = d.toLocaleDateString('en-GB', { day:'numeric', month:'short' }) +
             ' · ' +
             d.toLocaleTimeString('en-GB', { hour:'2-digit', minute:'2-digit' });
    var cls = r.score >= 80 ? 'high' : r.score >= 60 ? 'mid' : 'low';
    html += '<div style="...">' +
            '<span>' + ds + '</span>' +
            '<span class="score-pill ' + cls + '">' + r.score + '%</span>' +
            '</div>';
  });
  html += '</div>';
  document.getElementById('recentActivity').innerHTML = html;
}

.slice().sort() — Sort without mutation — .slice() creates a copy of the array first. Sort is then applied to the copy so the original results array is not reordered.

new Date(b.takenAt) - new Date(a.takenAt) — Date sorting — Subtracting two Date objects gives the difference in milliseconds. Positive means b is newer than a so this sorts newest first.

.slice(0,7) — Limit results — Shows only the most recent 7 quiz attempts to keep the panel compact. Only the last 7 after sorting by newest first.

toLocaleDateString and toLocaleTimeString — Date formatting — Converts MongoDB timestamp to readable format. en-GB locale gives day month format like 22 May · 10:30.

function renderTable(users, results) {
  // Build a map of userId → user object for quick lookup
  var userMap = {};
  users.forEach(function(u) { userMap[u._id] = u; });

  // Group all results by userId
  var userResults = {};
  results.forEach(function(r) {
    if (!userResults[r.userId]) userResults[r.userId] = [];
    userResults[r.userId].push(r);
  });

  // Build HTML table
  var html = '<table class="data-table"><thead><tr>' +
    '<th>Name</th><th>Email</th><th>Score</th>' +
    '<th>vs Bhutan</th><th>Attempts</th>' +
    '<th>Last Taken</th><th>Trend</th>' +
    '</tr></thead><tbody>';

  results.forEach(function(r) {
    var user     = userMap[r.userId] || {};
    var diff     = r.score - 80; // vs Bhutan average
    var cls      = r.score >= 80 ? 'high' : r.score >= 60 ? 'mid' : 'low';
    var attempts = userResults[r.userId] ? userResults[r.userId].length : 1;

    // Calculate trend (compare last two attempts)
    var trendStr = '—';
    var ua = userResults[r.userId] || [];
    if (ua.length >= 2) {
      var sorted = ua.sort(function(a,b){ return new Date(b.takenAt)-new Date(a.takenAt); });
      var td = sorted[0].score - sorted[1].score;
      trendStr = td > 0 ? '📈 +' + td + '%' :
                 td < 0 ? '📉 '  + td + '%' : '➡️ Same';
    }
    html += '<tr><td>' + (user.name||'Unknown') + '</td>...' + trendStr + '</tr>';
  });
  html += '</tbody></table>';
  document.getElementById('tableWrap').innerHTML = html;
}

userMap object — Hash map lookup — Creates a key-value object where the key is _id and value is the user object. Looking up userMap[userId] is instant compared to searching an array each time.

userResults grouping — Grouping by user — Creates an object where each key is a userId and the value is an array of all their results. Used to count attempts and calculate trend.

diff = r.score - 80 — Comparison — Compares each user's score to the 80% Bhutan benchmark. Positive diff means above average, negative means below. Displayed with + or - sign in the table.

Trend calculation — Progress tracking — For users with 2 or more attempts, compares their most recent score to their previous score. Shows 📈 if improved, 📉 if declined, ➡️ if same.

Building HTML table string — Dynamic table — The entire table including thead and tbody is built as a string and inserted once. This is faster than creating DOM elements one by one.

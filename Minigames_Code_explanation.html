JavaScriptPanel Toggle and XP System
minigames.html — JavaScript — Panel Toggle and XP
var totalXP = parseInt(localStorage.getItem("mg-xp") || "0");

function togglePanel() {
  var panel = document.getElementById("gamePanel");
  panel.classList.toggle("open");
}

function updateXP(earned) {
  totalXP += earned;
  localStorage.setItem("mg-xp", totalXP);
  var pct = Math.min((totalXP / 500) * 100, 100);
  document.getElementById("panelXpFill").style.width = pct + "%";
  document.getElementById("panelXpNum").textContent  = totalXP;
  document.getElementById("toggleXP").textContent    = totalXP + " XP";
}

function updateHighScores() {
  ["blitz","scam","memory"].forEach(function(g) {
    var hs = localStorage.getItem("mg-hs-" + g) || "0";
    var el = document.getElementById("hs-" + g);
    if (el) el.textContent = "Best: " + hs;
  });
}
window.addEventListener("load", updateHighScores);

localStorage.getItem with fallback — Persistent XP — Reads saved XP from localStorage on page load. The || "0" provides a fallback of "0" if no XP has been saved yet. parseInt converts the string to a number.

panel.classList.toggle("open") — Toggle class — Adds open if it is not there, removes it if it is. One function handles both opening and closing the panel.

Math.min(totalXP/500*100, 100) — Capped percentage — Calculates XP as a percentage of 500 maximum. Math.min caps it at 100 so the bar never overflows even if the player earns more than 500 XP.

Three elements updated simultaneously — Sync updates — When XP changes three elements are updated together: the panel fill bar, the panel number, and the toggle button XP display. All three always show the same value.

updateHighScores on load — Restore scores — Reads saved high scores from localStorage and updates the Best: display on each game card when the page loads so returning players see their previous best scores immediately.

JavaScriptStart Game and Show Result
minigames.html — JavaScript — Game Management
var currentGame = "";
var activeTimers = [];

function showScreen(id) {
  document.querySelectorAll(".game-screen").forEach(function(s) {
    s.classList.remove("active");
  });
  document.getElementById(id).classList.add("active");
}

function startGame(game) {
  currentGame = game;
  clearAllTimers();
  if (game === "blitz")  { showScreen("blitzScreen");  initBlitz();  }
  if (game === "scam")   { showScreen("scamScreen");   initScam();   }
  if (game === "memory") { showScreen("memoryScreen"); initMemory(); }
}

function goToMenu() {
  clearAllTimers();
  showScreen("menuScreen");
}

function clearAllTimers() {
  activeTimers.forEach(function(t) { clearInterval(t); clearTimeout(t); });
  activeTimers = [];
}

function showResult(score, max, xp, game) {
  var pct = max > 0 ? Math.round((score/max)*100) : 0;
  var emoji = pct >= 80 ? "trophy" : pct >= 60 ? "gold medal" : pct >= 40 ? "silver medal" : "bronze medal";
  var saved = parseInt(localStorage.getItem("mg-hs-" + game) || "0");
  if (score > saved) localStorage.setItem("mg-hs-" + game, score);
  document.getElementById("result-emoji").textContent = pct >= 80 ? "trophy" : "medal";
  document.getElementById("result-score").textContent = score + "/" + max;
  document.getElementById("result-xp").textContent    = "+" + xp + " XP earned!";
  updateXP(xp);
  updateHighScores();
  showScreen("resultScreen");
}

activeTimers array — Timer registry — All setInterval and setTimeout IDs are stored here. clearAllTimers loops through and clears every one. This prevents timers from a previous game continuing to run in the background.

showScreen removes all active then adds one — Exclusive screen — First removes active from all screens then adds it to only the target screen. This guarantees exactly one screen is visible at any time.

currentGame variable — State tracking — Stores which game is currently active. Used by the playAgain function to restart the correct game without needing to pass parameters.

High score comparison on result — Save best only — Compares the current score to the saved high score. Only saves if the new score is better. This ensures the Best: display always shows the all-time high score not the most recent score.

updateXP and updateHighScores called after result — Post-game sync — Both functions are called after every game result to keep the XP bar and high score displays up to date immediately after the game ends.

minigames.html — JavaScript — Game 1 Crypto Quiz Blitz
var blitzQuestions = [
  { q:"Bitcoin was created in 2009.", a:true,
    f:"Satoshi Nakamoto released Bitcoin in January 2009." },
  { q:"Bhutan mines Bitcoin using hydropower.", a:true,
    f:"Bhutan built one of Asia largest Bitcoin mining operations." },
  { q:"Crypto transactions are 100% anonymous.", a:false,
    f:"They are pseudonymous — wallet addresses are public." },
  // ... 12 questions total, 10 shown randomly
];

var blitzState = {};
var blitzTimerInterval = null;

function initBlitz() {
  blitzState = {
    questions: shuffleArray([...blitzQuestions]).slice(0, 10),
    current: 0, score: 0, answered: [], timeLeft: 30, running: true
  };
  renderBlitzQ();
  startBlitzTimer();
}

function renderBlitzQ() {
  if (blitzState.current >= blitzState.questions.length) {
    var xp = blitzState.score * 5;
    showResult(blitzState.score, 10, xp, "blitz");
    return;
  }
  var q = blitzState.questions[blitzState.current];
  document.getElementById("blitz-qtext").textContent = q.q;
  document.getElementById("blitz-qnum").textContent  = "Question " + (blitzState.current + 1);
  document.getElementById("blitz-score").textContent = blitzState.score;
  document.getElementById("blitz-q").textContent     = blitzState.current + 1;
}

function answerBlitz(ans) {
  if (!blitzState.running) return;
  var q = blitzState.questions[blitzState.current];
  var correct = (ans === q.a);
  if (correct) blitzState.score++;
  blitzState.answered.push(correct);
  updateBlitzDots();
  var fb = document.getElementById("blitz-feedback");
  fb.className = "feedback-box " + (correct ? "correct" : "wrong");
  fb.textContent = (correct ? "Correct! " : "Wrong! ") + q.f;
  fb.style.display = "block";
  blitzState.current++;
  setTimeout(renderBlitzQ, 1400);
}

function startBlitzTimer() {
  blitzTimerInterval = setInterval(function() {
    blitzState.timeLeft--;
    document.getElementById("blitz-time").textContent = blitzState.timeLeft;
    document.getElementById("blitz-timer-fill").style.width =
      (blitzState.timeLeft / 30 * 100) + "%";
    if (blitzState.timeLeft <= 0) {
      clearInterval(blitzTimerInterval);
      blitzState.running = false;
      showResult(blitzState.score, 10, blitzState.score * 5, "blitz");
    }
  }, 1000);
  activeTimers.push(blitzTimerInterval);
}

blitzQuestions array of objects — Question bank — Each question is an object with three properties: q (question text), a (correct answer true/false), f (explanation fact shown after answering). 12 questions shuffled to 10 each game.

blitzState object — Game state — All current game data in one object: shuffled questions, current index, score, answered history, time left, running flag. Resetting the game just means creating a new blitzState object.

ans === q.a comparison — Answer check — The player passes true or false. q.a is the correct answer. Strict equality === checks both value and type so true === true is correct and false === true is wrong.

setTimeout(renderBlitzQ, 1400) — Feedback delay — After answering there is a 1400ms pause showing the feedback before the next question renders. This gives the player time to read the explanation.

setInterval 1000ms timer — Countdown — Decrements timeLeft every 1000ms (1 second). Updates the display and timer bar proportionally. When time reaches 0 the interval stops and the result is shown regardless of progress.

var memoryPairs = [
  { term:"Bitcoin",    def:"First cryptocurrency, created in 2009" },
  { term:"Blockchain", def:"Decentralised digital ledger" },
  { term:"Wallet",     def:"Stores your private keys" },
  { term:"Seed Phrase",def:"12-24 words to recover wallet" },
  { term:"Mining",     def:"Creating new coins by solving puzzles" },
  { term:"DeFi",       def:"Decentralised financial services" },
  { term:"NFT",        def:"Unique digital ownership token" },
  { term:"GNH",        def:"Bhutan s happiness measure" }
];

function initMemory() {
  var pairs = shuffleArray([...memoryPairs]).slice(0, 6);
  var cards = [];
  pairs.forEach(function(p, i) {
    cards.push({ type:"term", text:p.term, pairId:i });
    cards.push({ type:"def",  text:p.def,  pairId:i });
  });
  memState = {
    cards: shuffleArray(cards),
    flipped: [], matched: [],
    moves: 0, timeElapsed: 0,
    running: true, canFlip: true
  };
  renderMemory();
  startMemTimer();
}

function flipMemCard(idx) {
  if (!memState.canFlip || !memState.running) return;
  if (memState.flipped.indexOf(idx) !== -1) return;
  if (memState.matched.indexOf(memState.cards[idx].pairId) !== -1) return;
  if (memState.flipped.length >= 2) return;

  memState.flipped.push(idx);
  renderMemory();

  if (memState.flipped.length === 2) {
    memState.moves++;
    memState.canFlip = false;
    var c1 = memState.cards[memState.flipped[0]];
    var c2 = memState.cards[memState.flipped[1]];
    if (c1.pairId === c2.pairId && c1.type !== c2.type) {
      // Match found
      setTimeout(function() {
        memState.matched.push(c1.pairId);
        memState.flipped = [];
        memState.canFlip = true;
        renderMemory();
        if (memState.matched.length === 6) {
          memState.running = false;
          var xp = Math.max(10, 40 - memState.moves);
          showResult(memState.matched.length, 6, xp, "memory");
        }
      }, 500);
    } else {
      // No match
      setTimeout(function() {
        memState.flipped = [];
        memState.canFlip = true;
        renderMemory();
      }, 800);
    }
  }
}

Eight pairs sliced to six — Random subset — All 8 pairs are shuffled and only the first 6 are used. This means each game presents different pairs making it feel fresh on replay.

pairId matching logic — Pair identification — Each card has a pairId matching its partner. c1.pairId === c2.pairId checks they are from the same pair. c1.type !== c2.type ensures one is the term and one is the definition — prevents matching two terms.

canFlip flag — Prevent spam clicking — Set to false when two cards are flipped and the match check is pending. Prevents the player from flipping more cards during the animation. Set back to true after the cards are matched or reset.

XP formula Math.max(10, 40-moves) — Performance-based XP — Fewer moves = more XP. 40 minus moves used. Math.max ensures a minimum of 10 XP even if the player takes many moves. Rewards efficiency and memory skill.

renderMemory on every flip — Full re-render — The entire card grid is rebuilt on every flip. This is simpler than updating individual cards. Each card checks memState.flipped and memState.matched to determine its current visual state.

JavaScriptUtilities — Shuffle Array
minigames.html — JavaScript — shuffleArray()
function shuffleArray(arr) {
  for (var i = arr.length - 1; i > 0; i--) {
    var j = Math.floor(Math.random() * (i + 1));
    var tmp = arr[i];
    arr[i] = arr[j];
    arr[j] = tmp;
  }
  return arr;
}

Fisher-Yates shuffle algorithm — Standard randomisation — The most reliable way to randomly shuffle an array. Loops from the end to the beginning. For each position picks a random earlier position and swaps them. Guarantees every permutation is equally likely.

Loops from length-1 down to 1 — Reverse loop — Going backwards means each element is swapped with an element in the already-processed section. This prevents elements from being swapped back to their original position.

Math.floor(Math.random() * (i+1)) — Random index — Math.random() gives 0 to 0.999. Multiplying by (i+1) gives 0 to i.999. Math.floor rounds down to give an integer from 0 to i inclusive. This picks a random index from the unprocessed portion of the array.

Called with spread [...] — Non-destructive — All calls to shuffleArray use [...array] to create a copy first. This shuffles the copy not the original so the question bank is never permanently reordered between games.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Cryptocurrency Readiness in Bhutan | DrukShift</title>
  <link href="https://fonts.googleapis.com/css2?family=Outfit..." rel="stylesheet">
  <script src="https://public.tableau.com/.../tableau.embedding...min.js"></script>

<!DOCTYPE html> — Declaration — Tells the browser this is a modern HTML5 document. Without this line the browser uses old rendering rules and the layout breaks.

<html lang="en"> — Root element — Opens the HTML document. lang="en" tells search engines and screen readers the page is in English.

meta charset="UTF-8" — Character encoding — Supports all characters including emojis, Bhutanese text and special symbols. Without this, characters show as question marks.

meta viewport — Mobile responsiveness — Makes the website fit the screen width of any device. Without this, the site appears tiny on phones.

title tag — Browser tab title — Sets the text shown in the browser tab and in Google search results.

Google Fonts link — External font import — Imports Outfit and Cormorant Garamond fonts from Google's servers. Outfit is used for body text, Cormorant for headings.

Tableau script — Third party library — Loads the Tableau JavaScript API. This is needed for Tableau visualizations to work on the page.

CSS Variables and Reset
index.html — CSS — Variables and Reset
:root {
  --navy:   #08192d;
  --deep:   #0f2a45;
  --blue:   #1a4a7a;
  --mid:    #2a6aad;
  --accent: #f4a261;
  --gold:   #e9c46a;
  --teal:   #2a9d8f;
  --red:    #e63946;
  --light:  #eef2f7;
  --white:  #ffffff;
  --muted:  #7a9bb5;
}
* { margin:0; padding:0; box-sizing:border-box; }
html { scroll-behavior:smooth; }
body { font-family:'Outfit',sans-serif; overflow-x:hidden; }

:root — CSS pseudo-class — Targets the root element of the document (html). Variables defined here are available everywhere in the CSS file.

--navy: #08192d — CSS custom property — A CSS variable. The double dash prefix defines a custom property. Used throughout as var(--navy) instead of repeating the hex code.

Why variables? — If the brand colour needs to change, it only needs changing once here and it updates everywhere automatically. This is a professional best practice.

* selector — Universal selector — Applies to every single HTML element. margin:0 and padding:0 remove default browser spacing. box-sizing:border-box includes padding in the element width calculation.

scroll-behavior:smooth — Scroll property — Makes anchor link scrolling animated and smooth instead of instantly jumping.

overflow-x:hidden — Overflow property — Prevents horizontal scrollbar from appearing when animations move elements slightly off screen.

position:fixed — Positioning — Removes the element from document flow and fixes it to the browser window. The nav stays at the top even when scrolling.

z-index:100 — Stack order — Controls which element appears on top when elements overlap. Higher number = appears on top. 100 ensures nav is above all page content.

display:flex — Flexbox layout — Makes the nav a flex container. Children (logo, links, button) are arranged in a row automatically.

justify-content:space-between — Flex alignment — Pushes the first child to the left and last child to the right with space between them.

rgba(8,25,45,0.92) — Semi-transparent colour — Same as --navy but with 0.92 opacity (92% visible). Makes the nav slightly see-through.

backdrop-filter:blur(12px) — Glass effect — Blurs the content behind the nav creating a frosted glass appearance. Modern browsers support this.

transition:color 0.2s — Animation — Makes the colour change on hover animate smoothly over 0.2 seconds instead of switching instantly.

  content: '';
  position: absolute;
  inset: 0;

              rgba(15,42,69,0.72) 50%, rgba(10,31,56,0.82) 100%);

@keyframes pulse {
  0%,100% { transform:scale(1); opacity:0.6; }
  50%     { transform:scale(1.1); opacity:1; }
}

min-height:100vh — Viewport height — vh means viewport height. 100vh means the hero is at least as tall as the full browser window height.

position:absolute; inset:0 — Full coverage — inset:0 is shorthand for top:0; right:0; bottom:0; left:0. Makes the slide fill its parent completely.

transform:scale(1.08) — Scale transform — Slides start slightly zoomed in at 108% size. When active they scale to 100% creating a gentle zoom-out effect.

opacity:0 / opacity:1 — Visibility — Non-active slides are invisible (opacity 0). The active slide is fully visible (opacity 1). JavaScript switches which one has the active class.

cubic-bezier(0.4,0,0.2,1) — Easing function — Custom timing curve for the transition animation. Creates a smooth ease-in-out effect that feels natural.

::after pseudo-element — CSS overlay — Creates a dark gradient overlay on top of each background image without needing extra HTML. Makes white text readable over bright photos.

nth-child selector — Specific child targeting — .hero-slide:nth-child(1) targets only the first slide, :nth-child(2) the second etc. Each gets a different background image URL from Unsplash.

@keyframes pulse — CSS animation — Defines a custom animation called pulse. The glow orbs use this to scale up and down continuously creating a breathing glow effect.

JavaScript Hero Slideshow
index.html — JavaScript — Hero Slideshow
var slideCaptions = ['Bhutan · Mountains','Blockchain · Future',...];
var currentSlide = 0, totalSlides = 5, slideTimer = null;

function goToSlide(n) {
  var slides = document.querySelectorAll('.hero-slide');
  var dots   = document.querySelectorAll('.hero-dot');

  // Outgoing slide — fade out and scale up
  slides[currentSlide].style.opacity   = '0';
  slides[currentSlide].style.transform = 'scale(1.12)';
  slides[currentSlide].classList.remove('active');
  dots[currentSlide].classList.remove('active');

  // Calculate next slide (loops back to 0 after last)
  currentSlide = (n + totalSlides) % totalSlides;

  // Incoming slide — reset then animate in
  setTimeout(function() {
    slides[currentSlide].style.opacity   = '1';
    slides[currentSlide].style.transform = 'scale(1)';
    slides[currentSlide].classList.add('active');
  }, 30);

  dots[currentSlide].classList.add('active');
}
function nextSlide()     { goToSlide(currentSlide + 1); }
function startSlideshow(){ slideTimer = setInterval(nextSlide, 4500); }
function stopSlideshow() { clearInterval(slideTimer); slideTimer = null; }
startSlideshow();

// Pause on hover
hero.addEventListener('mouseenter', stopSlideshow);
hero.addEventListener('mouseleave', startSlideshow);

var currentSlide = 0 — State variable — Tracks which slide is currently showing. Starts at 0 (first slide).

document.querySelectorAll — DOM selection — Gets all elements matching the CSS selector and returns them as a NodeList array. Used to access all slides and dots at once.

(n + totalSlides) % totalSlides — Modulo loop — The % (modulo) operator returns the remainder of division. When n exceeds totalSlides it wraps back to 0. This makes the slideshow loop infinitely.

setInterval(nextSlide, 4500) — Timer — Calls nextSlide every 4500 milliseconds (4.5 seconds) repeatedly. clearInterval stops it.

setTimeout with 30ms delay — Animation trick — Resets the incoming slide instantly then waits 30ms before animating it in. This tiny gap allows the browser to register the reset before starting the transition.

mouseenter/mouseleave events — Hover pause — Stops the automatic slideshow when the user hovers over the hero and restarts it when they move away.

index.html — JavaScript — Scroll Reveal
// Reveal cards on scroll
var revealObserver = new IntersectionObserver(function(entries) {
  entries.forEach(function(entry) {
    if (entry.isIntersecting) {
      entry.target.classList.add('visible');
      revealObserver.unobserve(entry.target); // Stop watching once revealed
    }
  });
}, { threshold: 0.1 });

document.querySelectorAll('.reveal').forEach(function(el) {
  revealObserver.observe(el);
});

// Animate progress bars when they scroll into view
var barObserver = new IntersectionObserver(function(entries) {
  entries.forEach(function(entry) {
    if (entry.isIntersecting) {
      var fill = entry.target;
      fill.style.width = fill.getAttribute('data-width') + '%';
    }
  });
});
document.querySelectorAll('.readiness-bar-fill').forEach(function(bar) {
  barObserver.observe(bar);
});

// Animate stat counters when they scroll into view
var counterObserver = new IntersectionObserver(function(entries) {
  entries.forEach(function(entry) {
    if (entry.isIntersecting) {
      animateCounter(entry.target);
    }
  });
});
document.querySelectorAll('.stat-num').forEach(function(el) {
  counterObserver.observe(el);
});

function animateCounter(el) {
  var target   = parseFloat(el.getAttribute('data-target'));
  var duration = 1500;
  var start    = performance.now();
  function update(time) {
    var progress = Math.min((time - start) / duration, 1);
    el.textContent = Math.floor(progress * target);
    if (progress < 1) requestAnimationFrame(update);
    else el.textContent = target;
  }
  requestAnimationFrame(update);
}

IntersectionObserver — Modern browser API — Watches elements and fires a callback when they enter or exit the visible screen area. Much better than scroll events because it does not run on every scroll pixel.

entry.isIntersecting — Visibility check — Returns true when the observed element has entered the viewport. False when it has left.

threshold:0.1 — Visibility amount — The callback fires when 10% of the element is visible. 0 would fire as soon as one pixel appears, 1 would wait until fully visible.

unobserve() — Stop watching — Once the reveal animation has played there is no need to keep watching the element. unobserve saves browser performance.

requestAnimationFrame — Animation loop — Browser function that runs a callback on the next animation frame (about 60 times per second). Smoother than setInterval for animations and pauses automatically on inactive tabs.

performance.now() — Timestamp — Returns the current time in milliseconds with high precision. Used to calculate animation progress based on elapsed time.

// ── FISHER-YATES SHUFFLE ──
function mgShuffle(arr) {
  for (var i = arr.length - 1; i > 0; i--) {
    var j = Math.floor(Math.random() * (i + 1));
    var tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp;
  }
  return arr;
}

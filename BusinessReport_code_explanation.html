Eight nav links — Section anchors — Each link uses href="#sectionid" to jump directly to that section of the report. This is the in-page anchor system — the # tells the browser to scroll to the element with that ID on the same page.

thead tbody semantic table — Proper HTML table — Using correct semantic table elements makes the table accessible to screen readers. thead marks column headers, tbody marks data rows. This is the correct HTML way to present tabular data.

th vs td — Header vs data — th (table header) cells get navy background white bold text. td (table data) cells get alternating row backgrounds and regular text. Browsers and screen readers treat them differently.

bar-fill inline style width and colour — Inline mini chart — The Visual column contains a mini progress bar inside the table cell. Each bar has its percentage width and colour set as inline styles since they are unique per row. This adds a visual dimension directly in the table.

Different colours per age group — Colour encoding — Blue for 18-24, teal for 25-34, gold for 35-44, orange for 45-54, red for 55+. The warm-to-cool colour shift visually encodes the readiness decline from young to old age groups.

nav-links display:none on mobile — Hidden mobile nav — The report navigation links hide on mobile. No hamburger menu is needed — readers use the Table of Contents section at the top to navigate. The back button to the main website stays visible.

All grids collapse to 1fr — Single column — TOC, solution cards, finding cards, GNH domains and tech cards all become single column on mobile. Content stacks vertically — all still readable just not side by side.

solution-card nth-child(5) grid-column:1 — Reset full width — The 5th solution card has grid-column:1/-1 for full width on desktop. On mobile this is reset to 1 because there is only one column anyway and 1/-1 could cause issues in some browsers.

stat-row stays 2 columns — Compact stats — Unlike the other grids stat-row keeps 2 columns on mobile. Three stat cards stacked one per row would look too spread out and wasteful of space. Two columns is compact and readable.
